# Deployment Gratis - Business AI Analyst V2

Aplikasi ini memakai repository lama dan Streamlit Cloud, jadi URL utama tidak perlu diubah.

- Panduan update langkah demi langkah: **`UPDATER_V2_PANDUAN_GITHUB.md`**.
- Dokumentasi semua fitur: **`README.md`**.
- Changelog migrasi: **`CHANGELOG_V2.md`**.

**Urutan aman:** buat `backup-v1` > buat `v2-test` > upload V2 ke `v2-test` > uji di Streamlit Cloud baru > merge ke `main` > tunggu aplikasi utama terupdate.

Repository: https://github.com/Piki-adriansyah/business-ai-analyst

URL yang sama sesudah merge: https://business-ai-analyst-piki.streamlit.app

Jangan commit file Excel, `.streamlit/secrets.toml`, atau API key publik.

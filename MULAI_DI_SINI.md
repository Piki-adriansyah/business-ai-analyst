# Business AI Analyst V2

**Untuk user GitHub yang sudah online:**

1. Pastikan website V1 masih bisa dibuka: https://business-ai-analyst-piki.streamlit.app
2. Baca `UPDATER_V2_PANDUAN_GITHUB.md`.
3. Buat `backup-v1` lalu `v2-test` di repo GitHub.
4. Ekstrak ZIP V2 dan push semua file ke branch `v2-test` (paling mudah via GitHub Desktop).
5. Uji branch itu di Streamlit Cloud, lalu merge ke `main`.
6. Website lama otomatis membaca source V2 dan **alamat tetap sama**.

Penting: data rahasia perusahaan tidak disertakan dalam source, dan tidak boleh diupload ke repository publik.

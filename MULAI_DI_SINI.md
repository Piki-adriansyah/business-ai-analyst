# MULAI DI SINI — BUSINESS AI ANALYST GRATIS

## Mau langsung dipakai orang lain dengan URL publik?

1. **Ekstrak ZIP** yang kamu download dari ChatGPT.
2. Buka https://github.com dan buat repository publik `business-ai-analyst`.
3. Upload **isi folder**, terutama `app.py`, `requirements.txt`, `src/`, `examples/`, dan `.streamlit/`.
4. Buka https://share.streamlit.io > **Create app**. Isi repository GitHub tadi dan file utama **`app.py`**.
5. Klik **Deploy**, lalu bagikan URL `.streamlit.app` yang diberikan. Coba tombol **Gunakan Data Demo** terlebih dulu.

Langkah rinci, termasuk jika gagal upload dan alternatif hosting gratis, ada di **`DEPLOY_GRATIS.md`**.

## Mau mencoba di Windows sebelum online?

1. Install Python 3.11 atau 3.12 dari https://www.python.org/downloads/ dan centang *Add Python to PATH*.
2. Double-click `JALANKAN_WINDOWS.bat` (perlu internet untuk install paket pertama kali).
3. Browser akan membuka `http://localhost:8501`. Klik **Gunakan Data Demo**.

## PENTING

- **Jangan upload Excel asli NICESO ke repository GitHub publik.** ZIP hanya memuat *data demo sintetis*.
- Untuk memproses Excel perusahaan di hosting pihak ketiga, pastikan telah ada izin dan pahami kebijakan privasinya.
- Fitur tanya-jawab analitik menggunakan aturan + SQL **gratis tanpa API**. AI generatif Gemini hanya aktif bila pemilik menambahkan API key sendiri dan pengguna menyetujuinya.
- Dataset di server hanya sementara. Ini aplikasi **MVP/demo**, bukan penyimpanan permanen atau sistem audit keuangan.
